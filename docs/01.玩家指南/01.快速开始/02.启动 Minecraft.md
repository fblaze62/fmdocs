在这一章节中，你可以了解到如何使用启动器、安装整合包、启动游戏等内容。如果你已经知道如何操作，请跳转到[下一章节](https://docs.fblaze62.top/guide/player/getting-started/join-game.html)。

## 启动器

启动器是用于启动 Minecraft 的工具。你可以在启动器中管理模组、实例（即游戏版本）等等。

如果你还在使用官方提供的启动器，请立即更换。不知道选择什么启动器？下面就介绍几个不错的启动器。

### PCL 社区版

PCL 社区版是 [Plain Craft Launcher 2 启动器](https://afdian.com/a/LTcat) 的社区衍生版本，补全了原版的许多功能，优化了界面，可以完全替代原版。

另外需要注意，这个启动器仅支持 Windows 平台。

你可以通过它的 [GitHub Releases](https://github.com/PCL-Community/PCL-CE/releases) 或QQ群 [FBlaze Matrix·Players](https://qm.qq.com/q/WXI8ntxaow) 的群文件下载。

::: tip GitHub Releases 无法访问 / 下载速度慢？
请使用 [Watt Toolkit](https://steampp.net/) 加速，并使用多线程下载器（如 [AB Download Manager](https://abdownloadmanager.com/#download)）下载。你也可以在QQ群 [FBlaze Matrix·Players](https://qm.qq.com/q/WXI8ntxaow) 的群文件中下载

### Axolotl Launcher

[Axolotl Launcher](https://axlmc.org/) 是一款比较新的启动器，其基于 [Modrinth App](https://modrinth.com/app) 开发，继承了 Modrinth App 界面美观、使用流畅、跨平台的特点的同时，还添加了诸如离线账户、CurceForge 支持的功能。

你可以通过它的[官网](https://axlmc.org/)或 [GitHub Releases](https://github.com/Mystic-Stars/Axolotl/releases) 下载，也可以在QQ群 [FBlaze Matrix·Players](https://qm.qq.com/q/WXI8ntxaow) 的群文件中找到安装包
:::
---

其他启动器大多功能不够全，在此就不介绍了。

## 安装整合包

整合包下载下来一般是一个`.mrpack`或`.zip`文件，大多数启动器直接拖入即可自动下载安装。

## 启动游戏

在启动器选择“羽焰的建筑”实例，直接启动即可。由于整合包内容较多，请耐心等待启动。
